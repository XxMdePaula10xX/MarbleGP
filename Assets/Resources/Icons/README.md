# Ícones da interface (Icons)

PNG **128×128 px, fundo transparente**, 1 arquivo por ícone. O jogo carrega
por código (`UIFactory.Icon("<key>", ...)`); se o arquivo não existir, o ícone
simplesmente não aparece (nada quebra).

## Já ligados no jogo (tela de Estratégia)

| Arquivo      | Uso                          |
|--------------|------------------------------|
| `tyre.png`   | Seção "Anel de aderência"    |
| `mode.png`   | Seção "Modo inicial"         |
| `laps.png`   | Seção "Duração"              |

## Sugeridos (podem ser ligados em seguida no HUD/telas)

- Estilo coerente entre todos (mesma espessura de traço / mesmo acabamento).
