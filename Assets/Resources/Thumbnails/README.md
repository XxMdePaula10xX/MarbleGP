# Miniaturas dos circuitos (Thumbnails)

Arte/mini-mapa top-down de cada circuito, exibida na tela "Escolha o Circuito".
Opcional: se não existir, a tela mostra só o texto.

## Nomes EXATOS dos arquivos (.png ou .jpg) — devem bater com o `trackId`

| Arquivo               | Circuito          |
|-----------------------|-------------------|
| `marble_park.png`     | Marble Park       |
| `neon_harbor.png`     | Neon Harbor       |
| `spiral_canyon.png`   | Spiral Canyon     |

(Os demais circuitos do campeonato completo podem ser adicionados depois, usando
o mesmo `trackId` como nome do arquivo.)

- Resolução recomendada: **512×512** ou **768×768**.
