# Texturas do cenário (Textures)

Texturas **tileáveis/sem emenda (seamless)** aplicadas na malha procedural da pista.
Opcionais: se não existirem, o jogo usa cores chapadas.

## Nomes EXATOS dos arquivos (.png ou .jpg)

| Arquivo        | Uso                          |
|----------------|------------------------------|
| `asphalt.png`  | Asfalto da pista             |
| `grass.png`    | Grama ao redor               |
| `curb.png`     | Zebra (curbing)              |

- Devem ser **seamless** (sem emenda ao repetir).
- Resolução recomendada: **1024×1024**.
- No Unity, marque a textura como **Wrap Mode = Repeat**.
