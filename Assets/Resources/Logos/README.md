# Logos das equipes (Logos)

PNG **256×256 px, fundo transparente**, 1 arquivo por equipe. O nome do arquivo
deve bater **exatamente** com o `teamId`. O jogo carrega por código
(`UIFactory.Logo("<teamId>", ...)`) — já aparece no card do vencedor (Resultado),
e pode ser ligado na torre de tempos depois. Se faltar, nada quebra.
